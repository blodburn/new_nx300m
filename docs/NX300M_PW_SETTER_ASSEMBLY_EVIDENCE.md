# NX300M Picture Wizard setter — offline ARM assembly evidence

> **Evidence version:** saved Ghidra result from the research **MFW 1.1 modified image, whose embedded SLP identifies Samsung 1.15**. This is NOT a verified NX300M 1.14 function and MUST NOT be used for device patching.

## Audited procedure

- Source: private `nx300m/analysis/nx300m_picture_wizard_setter.json`; generated by Ghidra. The original research evidence JSON and vendor ELF are **not** published with this repository.
- Procedure: `_Z18set_picture_wizardi` (`set_picture_wizard(int)`), address `0x90f2c` **in the older research build only**.
- Captured disassembly: **95 ARM instructions**; the saved decompiler pseudocode renders an empty return. The disassembly is more informative and is used as the limited evidence here.
- Parameter treatment: negative inputs become 0; values from 12 upward become 12. This is an observed **input clamp [0,12]**, **not proof that all 13 values are usable native style selections**.
- Local pointer data: thirteen `movw` plus thirteen `movt` instructions initialize **13 addresses**, and all visible `str` operations target the **local stack** via `sp`, `r11`, or a stack-derived `r3`.
- No visible `bl` or `blx` instruction in this function. Its Ghidra caller and callee lists in the saved evidence are both empty. Its last instruction is `bx lr`.
- No verified external write, native camera IPC method or image-style change appears in this specific function body. The static evidence suggests this function **does not itself perform a Picture Wizard update**; another route, indirect usage or different build must be investigated independently.

## Disambiguation of 12 and 13

| Claim | Evidence | Conclusion |
|---|---|---|
| 12 native Picture Wizard dispatches | Separate older Ghidra `picture_wizard_native_trace.json` | Reported **12 dispatch entries**, not automatically the entire UI mode count |
| 13 local pointer initializations | Setter assembly (`movw`/`movt` pairs) | **13 local pointers**, not proof of 13 usable native modes |
| 0..12 setter clamp | ARM compare / conditional move | An input bound for this function, not evidence of side effects |
| 13 Film Simulator looks | Research code `nx300m_film_menu.c` | **13 separate experiments** using unrelated FilmSim IDs |
| Picture Wizard behavior in actual 1.14 | No authenticated 1.14 ELF | **Unknown** |

**Do not equate any of these separate counts or treat a local pointer array as proof of a firmware integration hook.**

The read-only evidence classifier requires the exact expected named procedure, ordered instructions, bounds clamp, 13 pointer pairs, local-stack stores and a return with no visible direct call. Different patterns are classified as **insufficient evidence** and do not authorize any camera work. Seven synthetic instruction-list unit tests cover valid reference structure, an injected external call, a missing pointer initializer, a nonstack store, wrong procedure, invalid order and rejected paths.
